# Covenant probe

This lesson is the executable edge of [`HERESIES.md`](../../HERESIES.md): a
shared body constituted by explicit acts rather than a synchronized private
archive.

Learn it in a disposable instance with a real tool-capable mind:

```sh
SELF_HOME=/tmp/covenant-self SELF_MIND="opencode run" self learn lessons/covenant
SELF_HOME=/tmp/covenant-self self run covenant/propose garden "care for one garden"
# Replace PROPOSAL_SEQ with the sequence printed by the preceding command.
SELF_HOME=/tmp/covenant-self SELF_CALLER=alex self run covenant/answer PROPOSAL_SEQ accept yes
SELF_HOME=/tmp/covenant-self self show covenant
```

The current kernel does not authenticate `SELF_CALLER`, enforce multiple keys,
or provide co-custody. This probe tests the event vocabulary and human surface;
it must not be represented as cryptographic mutual consent.
